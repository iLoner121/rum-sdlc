# 管理仓库显示名与稳定身份

日期：2026-11-10。用户补充：不考虑假设旧客户端，现有数据可升级。状态：accepted（用户已确认的 T3 需求及本次实施授权）；实现在 app/repository_naming.go、repository_binding.go 与目录/同步入口；验收证据由 T3 管理记录保存。

管理仓库保留 RumSDLC_ 前缀。显示命名建议依次取用户输入、关联代码仓库名和 Project 显示名；用户可编辑建议，名称占用时显式选择，不能接管其他项目或自动追加随机后缀。Project ID 不从仓库名解析。

身份文件 .rumsdlc-project.json 保留 format/project_id/genesis，写入 name 供展示；当前三字段文件可读并在同步时更新，未更新前可回退读取 project-config.json，显示名不参与身份判断。发现前缀候选后读取身份文件，单项失败与格式无效分别显示；网络或授权失败不能当作缺失文件。旧项目无名称时显式退回本地名称或仓库名。

远端改名恢复要求同一 GitHub 数字仓库 ID、Project ID 和 genesis；所有校验通过后才更新当前绑定与本机 origin。历史快照中的旧名可在已验证的改名上下文下读取，最终同步内容更新为当前名。错误身份与异常 origin 拒绝自动恢复。既有长名称不强制改名，代码仓库关联与业务历史保持。
