# Task 活动记录

身份、Kind、状态与 result 以系统为准；此文只记一次实际活动，不另建分支或流程台账。未知部分可待确认，开始前要明确本次输入和结束条件。

## 本次活动与结束条件

当前要回答/完成的具体事情，预期产物、停止条件及已有授权；不把完整 Topic 流程塞进本活动。

## 输入与引用

需求/方案/验收判据、前置结论、实际基线和必要资料；只引用直接相关内容。

## 过程与产物

实际执行的方法/命令、观察、产物路径与日志引用；长报告另存并链接，不复制方案或 PRD 正文。

## 结果与结束判断

完成、失败、未知、未执行分别说明，提供证据。done 仅表示活动结束；缺条件尚未执行时不冒充完成。

## 交接与限制

下一活动需要的有效结论、未解决问题/恢复条件与输入。向 TASK_CONTEXT 回写最小交接，不累加全过程。
